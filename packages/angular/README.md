# @arxis/gtvzone-angular

Bindings de Angular (≥ 16.1) para gtvzone: `provideGtvNavigation()`, `GtvNavigationService`
(signals y `state$`) y las directivas standalone `gtvFocusable`, `gtvZone` y `gtvLayer`.

```html
<div gtvZone="row" gtvZoneStrategy="list">
  <div gtvFocusable="play" (gtvPress)="play()">Play</div>
</div>
```

Documentación completa en el [README del repo](https://github.com/renearias/gtvzone#readme).
